# Product scope

LASTLIGHT helps energy consultants and facility teams explore how local backup systems behave when grid power is lost. The intended journey is a night district, a selected building, its energy equipment, an outage, a visible failure point, and a comparison of improvements.

The school is the primary demonstration site. The clinic, small business and residential sites are synthetic archetypes. The current release is an interactive visual prototype. It has no measured building loads, grid topology or validated outage calculation.

The target engineering demonstration will use one simulation result for every displayed curve, figure and visual state. Each run will identify its inputs, units, assumptions, model version and data provenance. A visual change alone must never be presented as a calculated survival result.

LASTLIGHT is a scenario analysis tool for early design. It does not operate a live grid or provide regulatory engineering signoff.
