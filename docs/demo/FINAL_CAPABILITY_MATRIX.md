## Numerical boundary for presenters

- The authoritative calculation is `lastlight-dispatch-1.0.0`, schema `1.0.0`. Do not substitute the alternative PR #7 dispatch engine or its metadata.
- Every trace interval is `[t_utc, t_end_utc)`. A deficit beginning exactly at the horizon is not an observed failure in that run.
- "No observed failure in 12 hours" does not mean indefinite autonomy.
- The default school is synthetic. The solar generation input is zero, so visible rooftop PV is architecture, not power contributing to this reference calculation.
- The 36 kWh upgrade is a checked comparison. The separate 32 kWh result is the smallest passing member of a specified four-capacity live search. There is no validated price objective or monetary saving.
