# FragilityNet model card — first synthetic experiment

Model: **fragility-1-0e9fbf8a5ba1**. Physics label version:
**lastlight-dispatch-1.1.0**. Preprocessing: **input-statistics-1**.
Artifacts: `ml/artifacts/fragility-v1/` (18,365-byte PyTorch checkpoint,
normalization, baseline coefficients, versions and independent reports).

## Task and method

Binary classification: does a critical-load shortfall occur inside the supplied
outage horizon? Labels are generated by the event-split simulator. This model
does not predict the real-world probability of grid failure, certify an energy
system or replace physical dispatch. Regression for failure time or unserved
energy is not offered; those values are computed by physics.

There are 27 documented input-only features in `ml/features.py`: battery and
inverter configuration, load/PV statistics including an early-quarter mean,
duration, starting hour, grid fraction and compatibility/shedding flags. They
contain no outcome or simulation summary. Temporal ordering is compressed and
can be lost. Whole equipment groups are held out; see DATA_PROVENANCE.md.

Baseline: balanced logistic regression on the same normalized features. MLP:
27 → 64 ReLU → 32 ReLU → 1 logit. CPU AdamW, learning rate 0.002, weight decay
0.001, minibatch 256, fixed seeds, deterministic Torch algorithms. Training is
class-balanced, stops after 20 non-improving validation epochs, and restores
the lowest validation BCE state. The final run stopped at epoch 63. Temperature
scaling and an F2-selected classification threshold use validation only; the
final MLP threshold is 0.13, baseline 0.07. Normalization uses train only.

## Dangerous false negatives

Both test false negatives were re-run through physics:

1. `synthetic-20261024-000837`, 48 kWh / 2 kW inverter: a demand spike reaches
   2.0352 kW at 2.25 h while only 2 kW can be served. SOC is still 0.5079;
   stored energy does not remove an inverter power bottleneck.
2. `synthetic-20261024-004287`, 6 kWh / 8 kW inverter: the battery reaches
   minimum SOC 0.1 at 7.59756 h; 1.8778 kW critical demand is unserved with
   no solar at that point. Input statistics did not preserve enough temporal
   detail to reliably detect this depletion boundary.

There are seven further false negatives on unseen equipment. The evaluation
JSON retains replayable examples. This is why every prediction API response
contains a fresh physical result, even when the MLP predicts survival.

## Uncertainty, support and limitations

Inference validates finite features, shape, checkpoint checksum and feature/
physics versions. Observed train-range violations and unsupported sampling or
grid-charging modes produce explicit OOD warnings. Scores within 0.15 of 0.5
are marked uncertain; that is a heuristic, not a calibrated confidence interval.
All estimates have `physics_required=true` and `engineering_clearance=false`.
Rectangular feature bounds do not detect every unseen joint configuration.

Measured Frontier benchmarks do not demonstrate ML acceleration. The exact
full-trace-prefix method is faster and error-free on both inspected fixed-
equipment cases; it supplies the displayed map. ML remains a separately marked
proposal mechanism. Larger, richer datasets, temporal models, adversarial
boundary cases, regional validation and multi-run uncertainty studies are
future work, not implemented capabilities.
